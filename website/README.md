# Slim website

The marketing and documentation site for Slim, built with [Astro](https://astro.build) as a static site. It is a pnpm workspace package inside the Slim repository and reuses the app's design tokens (`src/styles/tokens.css`), button and logo components, so the site and the viewer share one visual language. Dark is the default theme, and light is one click away.

## Develop

From the repository root:

```bash
pnpm install
pnpm --filter slim-website dev      # http://localhost:4321
```

| Command | Purpose |
| --- | --- |
| `pnpm --filter slim-website build` | Static build into `website/dist` |
| `pnpm --filter slim-website check` | Type-check Astro, TypeScript and content schemas |
| `pnpm --filter slim-website test` | Unit tests (changelog parsing, citation, assets, no raw colors) |
| `pnpm --filter slim-website find-idc-examples` | Re-pick public IDC examples for the support matrix |
| `pnpm --filter slim-website verify-idc-examples` | Check the examples still resolve on the IDC proxy |
| `pnpm --filter slim-website capture-screenshots` | Re-capture app screenshots, thumbnails and the social card |

Set `PUBLIC_SLIM_DEMO_URL` to point the "Open in Slim" links at another Slim deployment. The default is the deployment that serves the IDC public proxy.

## Content

| What | Where |
| --- | --- |
| Feature sections | `src/content/features/*.md` |
| Showcase entries | `src/content/showcase/*.md` |
| Release highlights | `src/content/releases/*.mdx` |
| Changelog | Read from `docs/CHANGELOG.md` at build time, one page per version |
| DICOM support matrix | `src/data/matrix.ts` |
| IDC examples | `src/data/idc-examples.json`, generated by `scripts/find-idc-examples.mjs` |
| Citation | Read from `CITATION.cff` at build time |
| IDC logo | `public/brand/nci-idc.svg` (official NCI lockup, from the IDC portal) and `nci-idc-reverse.svg` (white wordmark for the dark theme), shown by `src/components/IdcLogo.astro` |

The IDC logo appears in the home hero, the "Developed and supported by" section on the home page, the about page, the footer and the social card. It links to IDC's page in the [Cancer Research Data Commons](https://datacommons.cancer.gov/repository/imaging-data-commons). Logos keep their own brand colors and live in `public/`, outside the token rule below.

Colors must come from the shared tokens. A test fails if `website/src` contains hex or `rgb()` literals; the only exception is the `theme-color` meta values in `src/data/theme.ts`, which a second test keeps in sync with the `--app` token.

## Screenshots

Screenshots show the real app on public IDC data. Run the app against the IDC proxy, then capture:

```bash
REACT_APP_CONFIG=preview \
SLIM_PREVIEW_DICOMWEB_URL=https://proxy.imaging.datacommons.cancer.gov/current/viewer-only-no-downloads-see-tinyurl-dot-com-slash-3j3d9jyp/dicomWeb \
pnpm start --port 3100

SLIM_APP_URL=http://localhost:3100 pnpm --filter slim-website capture-screenshots
```

To regenerate only the social card (`public/og.png`), which needs no running app, use `pnpm --filter slim-website capture-screenshots --only=og`.

The script uses the installed Google Chrome. Set `PLAYWRIGHT_CHANNEL=` to use Playwright's bundled Chromium instead (`pnpm exec playwright install chromium`).

## Deploy

The site is a second Firebase Hosting site, `slim-viewer`, in the `idc-external-006` project, next to the app. `website/firebase.json` targets that site, so the app's root `firebase.json` is unaffected.

One-time setup, by a project owner:

```bash
firebase hosting:sites:create slim-viewer --project idc-external-006
```

After that, `.github/workflows/deploy-website.yml` deploys every pull request that touches the site to a preview channel and comments the URL, and deploys `master` to <https://slim-viewer.web.app>. It reuses the `FIREBASE_SERVICE_ACCOUNT_SLIM` secret. A custom domain can be connected later in the Firebase console; update `SITE_URL` in the workflow when it is.

A weekly workflow, `.github/workflows/website-idc-examples.yml`, checks that every example in the support matrix still resolves on the IDC proxy and opens an issue when one breaks or a new IDC release changes the picture.
